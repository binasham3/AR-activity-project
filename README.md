# AR Web Application - Interactive Exhibit

## Project Description
This project is an interactive Augmented Reality (AR) web application built using A-Frame and AR.js. It features a themed marker-based AR scene anchored to the Hiro marker. The application includes a 3D model with a rotation animation, interactive primitives (a bouncing color-changing sphere and a scaling cylinder), a floating text label, and a dynamic status banner that updates in real-time when the marker is found or lost.
